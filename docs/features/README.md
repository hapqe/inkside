# Features

A closer look at each part of Inkside. Videos will be added here.

- [Write on PDFs](write-on-pdfs.md) — Lecture slides, textbooks and papers stay as they are. Your notes go on top.
- [Pen and brushes](pen-and-brushes.md) — Writing that feels natural, with a few fun extras.
- [Text and LaTeX](text-and-latex.md) — Type next to your handwriting, including typeset maths.
- [Pages and export](pages-and-export.md) — Rearrange a document and get a normal PDF back.
- [Search](search.md) — Find things in your documents, including your handwriting.
- [Ask the agent](ask-the-agent.md) — Circle something, then ask about it. The agent sees your marks.
- [Tutor](tutor.md) — An AI that asks before it tells.
- [Visualizations](visualizations.md) — Interactive pages the agent builds to explain something.
- [Dictation](dictation.md) — Speak your question instead of typing it.
- [Code](code.md) — Edit and run code on the same device.
- [Study week](study-week.md) — See when you studied.
- [Projects and themes](projects-and-themes.md) — Keep subjects apart and make the app yours.
- [Sync across devices](sync.md) — Tablet, phone and computer, all with the same documents.
