# Ask the agent

Circle something, then ask about it. The agent sees your marks.

> 🎬 Video: coming soon

![Ask the agent](../screenshots/06-chat.png)

## What it does

- Mark a part of the page with a box, underline or circle, then ask in the chat.
- Your marks are sent with each message, so "explain the blue box" or "replace the for loop in the blue box with map" points at the right thing.
- The chat sits next to your document, with answers in LaTeX.
- Needs a connected computer with your Claude subscription or API key; see [Connecting a computer](../connecting.md).
